# TriBot Bot 团队 · DSH 插件

把一支**分工明确的 Bot 团队**装进你的 DeepSeek Harness：选一个角色，就切到那套方法论和输出契约；不用搭多进程、不用写提示词。

一句话：**总管拆解 · 研究员查证 · 工程师动手 · 管家巡检 · 审稿人挑刺**——五个角色装在一个插件里。

## 亮点

- **一次安装，五种专精**：host 半把五套完整方法论（怎么做、什么算合格、不能做什么）和五套输出契约直接注册成 `/tribot` 技能，选角色 = 换工作模式。
- **直接入戏**：点名角色 + 任务时，状态行之后紧跟实质动作——禁止「作为 X，我将…」式旁白。
- **质量纪律有实测**：同一交接文档任务三轮对比——单干 ≈¥0.35；团队 v1（全量重读）≈¥1.28（3.7×）；**团队 v2（上下文经济）≈¥0.39，成本与单干持平**，且轻审 60 处抽验抓到 1 处真实错误（路由数 54→58，已独立复核修正）。深审模式按需开启。
- **每会话选角开关**：胶囊旁的小开关按会话记忆——关掉的会话隐藏选角 UI、停用 `#` 菜单并立即退出角色，其他会话不受影响；新会话默认开启。
- **角色有记忆**：选过的角色按会话记住（新会话沿用上一个对话的角色），发送消息后胶囊不会弹回「选择角色」。
- **零配置**：不联网、不写文件、不需要任何密钥或环境变量，装完即用。

## 五个角色

| 角色 | 专精 | 典型交付 |
|---|---|---|
| 🧭 **总管** | 任务拆解、并行分派、验收与合并；不亲自调研、不亲自写码 | 结论 + 依据 + 未完成 + 下一步 |
| 🔍 **研究员** | 多角度检索、A/B/C 来源分级、交叉验证、冲突裁决 | 带链接与日期的要点清单 |
| 🛠 **工程师** | 先读后写、最小改动、写完必验、失败贴原始报错 | 改动 + 验证输出 + 风险 |
| ⏰ **管家** | 巡检清单化、阈值判级、只报变化 | 200 字内状态/异常/建议 |
| 🧪 **审稿人** | 结论与证据一致性、引用可信度、边界与可执行性 | 通过/需修改/拒绝 + 问题清单 |
| 👥 **团队** | 总管 → 专家 → 审稿人流水线（含子代理会话复用与冷启动规则） | 完整交付物 |

## 省 token 怎么省的

插件的**上下文经济规则**是硬规则，不是建议：

- **阅读预算**：先列阅读清单再读；大文件结构优先；连续阅读超 2,000 行必须说明理由
- **审稿两级制**：默认轻审（审交付物 + grep 抽验 ≥30% 关键引用，**不通读仓库**）；深审按需
- **回执蒸馏**：给总管的回执 ≤40 行，禁止大段粘贴工具输出
- **检索预算**：同一方向最多 3 轮，够即停
- **委派优先 fork**：`subagent_fork` 继承父会话已完成轮次，首轮直接命中父缓存（`subagent` spawn 是全新前缀、首轮全价）；fork 时不传 provider/model 覆盖
- **复用子代理会话**：同一专家的多个子任务在同一子代理里继续；小交付总管自审，不外派

> 同一交接文档任务实测：单干 ≈¥0.35；团队 v2 ≈¥0.39（持平），且多出一层 grep 级验证。

## 安装

```bash
dsh plugin --profile desktop add dsh-tribot-team
```

装完重启 DSH。之后：

```
/tribot 总管
```

或点输入框旁的「选择角色」胶囊。不点名时它会先给菜单，回编号即可：

```
1. 🧭 总管   2. 🔍 研究员   3. 🛠 工程师
4. ⏰ 管家   5. 🧪 审稿人   6. 👥 团队
```

## 使用示例

```
/tribot 工程师 把这个构建错误修好并给出验证输出
```

```
/tribot 研究员 查一下这个说法有没有一手来源
```

选定角色后，每条回复第一行都会标出当前角色：

```
> 🛠 **当前角色：工程师** · TriBot 3/6
```

## 配置

**无需任何配置**：没有环境变量、没有密钥、没有后台服务。技能内容仅在显式调用时注入，不占常驻上下文。

## 相关仓库

- [P3NN4L/Tribot](https://github.com/P3NN4L/Tribot) —— TriBot 桌面版 monorepo；同一个技能的 **skill 型安装**（DSH Market 已收录，git clone 到技能目录即可，零依赖但无选角胶囊）。两个条目二选一安装，同名技能请勿同时安装。

## 开发

```bash
npm install
npm run build     # 产出 lib/index.js（host，注册技能）与 lib/client.js（选角胶囊）
```

技能本体在根目录 [`SKILL.md`](SKILL.md)（host 构建时内嵌，也可单独复制到 `~/.dsh/skills/tribot/` 手动安装——但那样没有选角胶囊）。
