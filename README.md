# dsh-tribot-team

DeepSeek Harness 插件：**TriBot Bot 团队**。一次安装，同时获得：

- 🧭🔍🛠⏰🧪 **五角色技能**（`/tribot`）——总管拆解、研究员查证、工程师动手、管家巡检、审稿人挑刺，每个角色有独立方法论、质量门槛、硬输出契约
- 🎛 **输入框选角胶囊**——点一下选角色，自动填入 `/tribot 工程师 `，不用记命令
- 💬 **每会话开关**——胶囊旁的小开关按会话记忆，关掉的会话立即退出角色，其他会话不受影响

> 纯指令 + 前端 UI：不联网、不要密钥、没有后台服务。数据不出本机。

## 安装

```bash
dsh plugin --profile desktop add dsh-tribot-team
```

装完重启 DSH。之后：

```
/tribot 总管
```

或点输入框旁的「选择角色」胶囊。不点名时它会先给你菜单：

```
1. 🧭 总管   2. 🔍 研究员   3. 🛠 工程师
4. ⏰ 管家   5. 🧪 审稿人   6. 👥 团队
```

## 五个角色

| 角色 | 专精 | 典型交付 |
|---|---|---|
| 🧭 **总管** | 任务拆解、并行分派、验收与合并 | 结论 + 依据 + 未完成 + 下一步 |
| 🔍 **研究员** | 多角度检索、A/B/C 来源分级、交叉验证 | 带链接与日期的要点清单 |
| 🛠 **工程师** | 先读后写、最小改动、写完必验 | 改动 + 验证输出 + 风险 |
| ⏰ **管家** | 巡检清单化、阈值判级 | 200 字内状态/异常/建议 |
| 🧪 **审稿人** | 结论与证据一致性、引用可信度、查夸大 | 通过/需修改/拒绝 + 问题清单 |
| 👥 **团队** | 总管 → 专家 → 审稿人流水线 | 完整交付物（同一 Agent 内切换） |

## 质量：实测过的两个卖点

**对抗审查有牙齿**：团队模式的轻审 60 处抽验，实测抓到 1 处真实事实错误（路由计数 54→58）并在交付前修正。

**上下文经济**：审稿默认「轻审」（审交付物 + grep 抽验 ≥30% 关键引用），不重读仓库；工程师/研究员有阅读与检索预算；回执强制蒸馏。同一交接文档任务实测：

| 模式 | 输入 | 成本 |
|---|---:|---:|
| 不用 skill（单干） | ≈90k tokens | ≈¥0.35 |
| 团队 v2（本插件） | ≈135k tokens | ≈¥0.39 |

**≈持平的价格，多一层验证过的质量**；高风险交付说一声「深审」，审稿人才会通读相关代码。

## 每会话开关

- 胶囊旁的小开关：关 = 当前会话隐藏胶囊、停用 `#` 菜单、立即退出 TriBot 角色
- 其他会话不受影响；新会话默认开启；重启 DSH 后各会话回到自己上次的选择

## 配置

**无需任何配置**：没有环境变量、没有密钥。技能内容仅在显式调用时注入，不占常驻上下文。
